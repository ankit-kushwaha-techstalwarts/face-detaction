🔒 Security & Compliance

📋 Compliance Information

Session Timeout — Auto-logs out inactive users. Set 0 to disable. Recommended: 30 minutes for government deployments.

Data Retention — Attendance records older than this limit can be archived. Default: 1095 days (3 years).

Audit Log — All admin actions (login, edit, delete) are recorded automatically and cannot be disabled.

Password Policy — Enforces minimum length and complexity for all system users.

Failed Login Limit — Accounts are flagged after N consecutive failures. Set 0 to disable lockout.

✅ Audit logging is always active

Every login, data change, and configuration update is logged with user, IP, and timestamp.
